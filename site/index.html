The core loop

An operator, not a scanner

Nmap, Nessus, Burp and Nuclei are tools you point. tyto is driven by a model that decides what to do next from the engagement's context, adapts to findings mid-run, and re-plans — while a guard it cannot override decides what's permitted.

The Scope Guard

The model proposes. The guard disposes.

Every proposed action is forced through a deterministic guard before anything touches a target. It gates on the authoritative tool metadata — never on what the model claims — and it fails closed. An unknown tool, an out-of-scope target, or a risk above the ceiling is denied, full stop.

ALLOW — in scope, within ceiling REQUIRE_APPROVAL — human signs off DENY — out of scope / over ceiling

No covering grant, no action

High-risk or exploit-category actions need a verified authorization covering the target, or a recorded self-attestation for assets you own.

Human in the loop

Mutating commands wait

Any non-read-only command through the full-arsenal tool is forced to an explicit operator approval before it runs.

Provable

Tamper-evident audit

Every decision, action and result is written to a hash-chained log, so the report matches exactly what ran.

Scope as code

Who hired you, what they own, what you may touch

An engagement is a file. The guard enforces it; the model reads it as context. Load a bug-bounty program's published scope and tyto physically cannot fire a tool at anything outside it.

# engagement.yaml
client: Acme Corp
authorization:
  mode: self-attested   # or a client-signed grant
scope:
  in_scope:
    - { type: domain, value: app.acme.com }
  out_of_scope: []
rules_of_engagement:
  max_risk: medium
  allowed_categories: [recon, scan]
  max_requests_per_second: 8

⚠ Authorized testing only. tyto refuses to act against any target that is not explicitly in-scope for a loaded, acknowledged engagement. Using it against systems you do not own or have written permission to test is illegal. The scope you load is the authorization — testing outside it is not sanctioned, no matter what the model proposes.
